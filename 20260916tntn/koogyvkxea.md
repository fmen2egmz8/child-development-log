# 取卵前后注意事项

> 更新时间：2026-09-16 (UTC+8)

- 
取卵日早上可少量清淡饮食，准备一些高热量食物如巧克力等。

- 
女方尽量穿宽松易穿脱的衣服，不化妆，不涂抹香水。

- 
取卵当天，务必携带双方结婚证，身份证，（如果是二胎，需要带二胎证，证件均为原件），如未带或少带者将不给予取卵等后续安排，本周期作废。

- 
取卵日，男女双方同时来院，早上7点到南楼生殖科，找边老师安排。

- 
取卵当日，无需紧张，疼痛在可承受范围内，可听音乐放松心情。

- 
阴道冲洗过后由护士带领去准备室换手术衣，带口罩帽子。

- 
取完卵后，去注射室等待告知如何用药，何时再来医院就诊。

- 
取卵后，禁止性生活，游泳，盆浴可以淋浴，不能干重体力活，也不用绝对卧床休息，可适当活动。

- 
可选择易消化饮食，避免便秘或腹泻，可选食物如芹菜，白菜山药冬瓜等，另外可适当吃些粗粮，少吃辛辣刺激性食物，还应与高蛋白，鸡鸭鱼肉等搭配。可适当听舒缓音乐放松心情。

- 
若取卵后出现少量出血，轻微下腹坠痛，头晕，恶心应卧床休息多饮水，若第二天上述情况未改善，或加重应及时来院就诊。
